# Asistente de Movilidad con IA para Discapacidad Visual

Prototipo académico de un asistente web de asistencia visual que utiliza una **arquitectura desacoplada** para la detección y orientación espacial de obstáculos en tiempo real.

## 🚀 Arquitectura del Sistema
*   **Backend:** Python con un servidor HTTP nativo, integrando procesamiento analítico y conectividad de visión artificial.
*   **Frontend:** Interfaz web accesible de alto contraste optimizada para baja visión utilizando HTML5, CSS3 y JavaScript Vanilla (APIs nativas `getUserMedia` y Web Speech API).

## 🛠️ Instalación y Uso
1. Descarga o clona este repositorio.
2. Abre una terminal en la carpeta `backend-api/`.
3. Ejecuta el servidor con: `python main.py`.
4. Abre el archivo `frontend-web/index.html` en tu navegador web.
